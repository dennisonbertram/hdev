hdev

Hand a coding task to an agent on a throwaway Hetzner VM. Close your laptop. It comes back as a pull request.

Get started

# 1. install the skill into your agent
npx skills add dennisonbertram/hdev

# 2. point it at your Hetzner account
hcloud context create hdev

# 3. put your Claude subscription on the box, once
hdev login

# 4. build the base image, once (~2 min)
hdev image

# 5. go
hdev submit -m "add a --version flag and a test for it"

Full walkthrough, including getting a Hetzner token: SETUP.md

How it works

What you can do

hdev submit plan.md
One VM per ## Slice: heading. Slices run in parallel and each opens its own PR.
hdev ps
Every job, its status, and how long its VM has been alive.
hdev status <job>
The agent's own progress notes. No model call, so it costs nothing.
hdev ask <job>
Question the running agent. It answers with its full context; its own thread is untouched.
hdev image browser
Profile snapshots — headless Chromium, or Docker — so the toolchain is installed once, not per job.
hdev reap
Delete finished VMs. --max-age 4h also clears runaways and anything a crashed submit left behind.

A job costs about $0.02 of Hetzner time. Your Claude subscription covers the rest. How it works in detail →
